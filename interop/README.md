# UBIN 2 Polyglot Conformance

The `interop/` directory contains independent reference implementations of the frozen UBIN Protocol 2 byte contract.

- `c/` — C11 envelope plus allocation-neutral canonical writer/reader primitives
- `cpp/` — C++17 envelope and canonical writer helpers
- `java/` — Java 17 envelope and full canonical value encoder/decoder
- `conformance/vectors.json` — authoritative stable vectors generated by the Python reference

These implementations do not attempt to make unrelated programming languages source-API-identical. They prove that each language can produce and consume the same language-neutral bytes. New language implementations should follow `docs/PROTOCOL_V2.md` and use the same vector file.
